# My Website

A simple, clean website starter project with HTML, CSS, and JavaScript.

## Features

- Clean and simple structure
- Responsive design
- Form handling with JavaScript
- Smooth scrolling navigation

## Project Structure

```
my-website/
├── public/                   # Static files (HTML, CSS, JS)
│   ├── index.html           # Main landing page
│   ├── styles.css           # Global styles
│   └── app.js               # Application logic
│
├── docs/                     # Documentation
│
├── src/                      # Source code (future)
│
├── package.json              # Project dependencies
├── .gitignore               # Git ignore file
└── README.md                # This file
```

## Installation

1. Clone the repository:
```bash
git clone https://github.com/MengnyYorn/my-website.git
cd my-website
```

2. Install dependencies:
```bash
npm install
```

## Running the Application

Start a local server:
```bash
npm start
```

Or simply open `public/index.html` in your browser.

## File Descriptions

- **public/index.html** - Main HTML page with sections for Home, About, and Contact
- **public/styles.css** - Styling for headers, navigation, forms, and footer
- **public/app.js** - JavaScript for form handling and smooth scrolling

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
